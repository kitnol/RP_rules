# HOM Правила — editable reconstruction

This is a clean React/Vite reconstruction of the recovered site.

### Edit content
Change `src/content.ts`.

### Edit design
Change `src/styles.css`.

### Edit behavior
Change `src/main.tsx`.

### Run
`npm install`
`npm run dev`

### Build
`npm run build`

Netlify settings are already in `netlify.toml`: build `npm run build`, publish `dist`.
